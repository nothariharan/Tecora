## FAQ

### Is Tecora an AI chatbot?

No. Tecora doesn’t answer prompts or wrap models. It organizes chats from Claude, ChatGPT, and Gemini.

### Does my data leave my computer?

Chat data Tecora stores stays in your browser’s local storage (IndexedDB). There is no Tecora backend for syncing your chats.

### Do I need a Tecora account?

No.

### Which browsers are supported?

v0.1 targets Chromium via a Manifest V3 extension (Chrome-class browsers). Check the download section for the current build.

### Which sites does it work on?

`claude.ai`, `chatgpt.com`, and `gemini.google.com`.

### Can I turn off message storage?

Yes. Per-platform toggles can keep capture to titles/metadata and remove stored message text.

### Will this show my exact ChatGPT / Claude quota?

Not today. Usage awareness is a **local estimate** from captured activity, labeled clearly. Real platform usage APIs are on the roadmap.

### Can I back up folders and tags?

Yes. Portable JSON archive export/import restores chats, messages, folders, and tags.

### Is bulk delete safe?

It’s powerful and irreversible on the platform. Tecora uses a safety-gated queue and asks you to keep the site tab open. Read the confirm copy before running it.

### Is this free?

For the hackathon / current distribution, treat install as free unless the download section says otherwise. There is no SaaS billing in v0.1.
