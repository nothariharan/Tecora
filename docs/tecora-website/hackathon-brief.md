# Hackathon brief

How to present Tecora as a product submission with the landing page as the front door.

---

## Submission one-liner

**Tecora** — a local-first Chrome extension that organizes AI chats across Claude, ChatGPT, and Gemini with folders, search, export, and cleanup — no account, no backend.

---

## Problem → solution → demo

| Beat | Say this |
| --- | --- |
| Problem | People use multiple AIs; history is fragmented and hard to reuse |
| Insight | The missing layer isn’t another chatbot — it’s local memory & organization |
| Solution | Tecora captures chats on-device and gives you a cross-platform library |
| Why now | Multi-model usage is normal; privacy-sensitive users reject “upload your chats” tools |
| Demo | Install → open 2 platforms → folder/tag → Ctrl+K → export → privacy toggle |
| Ask | Judges try the Download path and poke the side panel |

---

## Judging angles (map strengths)

| Criterion (typical) | Tecora proof |
| --- | --- |
| Originality | Not another GPT wrapper; organization layer |
| Technical depth | MV3 intercept + adapters + Dexie + MiniSearch + Shadow DOM UI |
| UX | Side panel + palette + τ dock; mono calm UI |
| Impact | Daily pain for multi-model users; portable archives |
| Privacy | No backend; capture toggles; wipe |
| Polish | Landing page tells the story; product already usable in v0.1 |

---

## What to show on stage / video (order)

1. Cold open: messy multi-AI workflow (5s)  
2. Hero of landing page → Download  
3. Live: chats appear in Tecora  
4. Organize + All platforms resume  
5. `Ctrl/Cmd+K` search moment  
6. Export archive/ZIP mention  
7. Privacy line on-screen: “Nothing leaves the device”  
8. Close on τ + Download  

---

## Landing page’s job in the hackathon

| Job | How |
| --- | --- |
| Explain fast | Hero + 01/02/03 sections |
| Look premium | Prime UI–grade structure + Tecora mono brand |
| Convert | Download CTAs everywhere |
| Answer skeptics | FAQ (wrapper? cloud? quota?) |
| Point to proof | Demo link / GitHub / install steps |

The site is **not** the product. Don’t spend the whole page on metaphor; show the extension.

---

## Claims checklist before submitting

- [ ] Never say “AI wrapper” as a positive self-description  
- [ ] Never claim exact platform quota  
- [ ] Never claim ChatGPT Projects support  
- [ ] Never claim a Tecora cloud  
- [ ] Do claim local-first + three platforms + organize/search/export  
- [ ] Do show honest Gemini/message-capture limits if asked

## Elevator pitch (30 seconds)

> We don’t use one AI anymore — we use three. But our history is still trapped in separate sidebars. Tecora is a local-first Chrome extension that captures chats from Claude, ChatGPT, and Gemini into one private library with folders, search, and export. There’s no Tecora account and no backend. Nothing leaves your device. It’s the organization layer multi-model work was missing.

---

## Elevator pitch (10 seconds)

> Tecora organizes your Claude, ChatGPT, and Gemini chats locally — folders, search, export — with no cloud and no account.
