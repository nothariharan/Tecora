# Illustrations

Direction for the cool, section-tied illustrations (Prime UI style craft, Tecora mono identity).

---

## Principles

1. **Product-real** — show side panel, palette, τ dock, folders — not random 3D toys  
2. **One metaphor per section** — capture / organize / search / export / privacy  
3. **Mono materials** — charcoal glass, white ink, soft gray depth; color only as tiny platform dots if needed  
4. **No sticker overlay** — don’t float “New!” badges on hero art  
5. **Edge-to-edge optional** — hero can be a full-bleed dark plane; section arts can be contained  
6. **Honest UI** — stylized OK; don’t fake ChatGPT Projects support or quota rings we don’t have  

---

## Style recipe

| Attribute | Direction |
| --- | --- |
| Medium | Soft 3D + flat UI hybrid (Prime-like), or high-end flat vector |
| Lighting | Single soft key light on black; gentle specular on glass |
| Edges | Crisp panels, 4–8px radius |
| Depth | 1–2 layers max (panel + glow wash) |
| Glow | Optional desaturated halo behind τ — never rainbow |
| Texture | Very light noise OK; no busy gradients |
| People | Prefer no stock humans; product is the character |

## Illustration inventory

### H1 — Hero

**Concept A (preferred):** Floating τ dock + ghosted side panel, slightly perspective, on black.  
**Concept B:** Giant τ carved from matte black material with a white edge light.  
**Concept C:** Abstract “three streams → one shelf” library.

**Must include:** recognizable Tecora brand.  
**Avoid:** blue CTA baked into the image; cluttered multi-window desktop screenshots.

---

### I1 — Capture (`01`)

**Concept:** Three thin pipes or cards labeled Claude / ChatGPT / Gemini flowing into a single IndexedDB/library block marked τ.

**Motion pair:** streams animate in sequence, then settle.

---

### I2 — Organize (`02`)

**Concept:** Side panel crop showing folders, a pin, tags, and “Continue where you left off”.

**Details to show:** All platforms scope, a derived title, a one-line preview.

---

### I3 — Search (`03`)

**Concept:** Command palette floating over a darkened page, query typed, results across platforms, keyboard chip `⌘K` / `Ctrl K`.

**Tone:** fast, precise, Shadow-DOM “on top of the host page”.

---

### I4 — Export

**Concept:** Stack of outputs — `.md`, archive `.json`, `.zip` — with a small `MISSING.md` card as an honesty badge.

**Optional:** tiny artifact / image thumbnails being packed.

---

### I5 — Privacy

**Concept:** Device silhouette; data dots stay inside. Toggle row “Message content capture”. No cloud upload arrow.

**Line overlay:** “No account · No backend”.

---

### I6 — Surfaces tabs

Four mini-compositions reused from product:

1. Side panel  
2. Palette  
3. τ dock hover-expand  
4. Privacy & activity  

---

### I7 — Feature carousel slides

Simple iconic panels (one symbol each):

| Slide | Symbol idea |
| --- | --- |

---

## Platform marks

Use official names in text. For glyphs in illustrations:

- Prefer **text labels** or abstract monochrome marks  
- If using brand logos, follow each company’s brand guidelines / hackathon fair-use norms  
- Safe alternative: plain word chips `Claude` `ChatGPT` `Gemini` in muted pills  

---

## Production notes

| Need | Suggestion |
| --- | --- |
| Speed for hackathon | Figma mockups of real UI + light polish beats weak AI art |
| Consistency | Shared camera angle / same panel chrome across I2–I6 |
| Export | SVG/PNG @2x; dark background baked or transparent |
| Alt text | Describe function (“Tecora side panel with folders and resume”) |

---

## Reference mood (do / don’t)

**Do feel like:** Linear, Raycast, Arc marketing — calm product theater.  
**Also do feel like:** Prime UI’s *section craft* and illustration scale.  
**Don’t feel like:** Crypto dashboard, purple AI startup template, newspaper editorial, terracotta cream landing.
