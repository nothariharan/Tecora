# Use cases

Concrete scenarios for landing-page examples, illustrations, and hackathon storytelling.

---

## 1. The multi-model worker

**Scene:** A builder uses Claude for long reasoning, ChatGPT for quick drafts, Gemini for Google-connected tasks.

**Pain:** Three histories, zero shared structure.

**With Tecora:** Folders like `ship`, `research`, `personal`. Tags like `#launch`. Resume the right thread from **All platforms**.

**Landing line:** Work across models. Remember in one place.

---

## 2. “I know I already figured this out”

**Scene:** Someone hit a weird bug last Tuesday. The fix is buried in a chat titled “New chat.”

**Pain:** Native search is per-site and titles are useless.

**With Tecora:** Derived titles + one-line previews + full-text `Ctrl/Cmd+K`.

**Landing line:** Find the answer you already earned.

---

## 3. Course / research archive

**Scene:** A student has weeks of tutoring chats, paper outlines, and code help.

**Pain:** Exams come; the sidebar is chaos; nothing is portable.

**With Tecora:** Tag by course. Export markdown or ZIP with assets. Keep a JSON archive as a personal backup.

**Landing line:** Turn chat history into something you can keep.

---

## 4. Machine switch / wipe-and-restore

**Scene:** New laptop, or a browser profile reset.

**Pain:** Chat sites keep cloud history, but *Tecora organization* (folders/tags) would be lost without export.

**With Tecora:** Portable JSON archive export → import on the new profile.

**Landing line:** Your library moves with you — still local.

---

## 5. Privacy-conscious power user

**Scene:** User wants organization but not a third party reading message bodies.

**Pain:** Most “AI memory” tools want an account and a server.

**With Tecora:** No Tecora account. Optional message capture off → titles/metadata only. Wipe anytime.

**Landing line:** Organize without uploading.

---

## 6. Cleanup day

**Scene:** Hundreds of dead-end chats clog the native UI.

**Pain:** Deleting one-by-one is miserable; mistakes are easy.

**With Tecora:** Select mode → safety-gated bulk delete queue (platform tab stays open).

**Landing line:** Clean house without losing the threads that matter.  
*(Keep marketing careful — deletion is irreversible on the platform.)*

---

## 7. Hackathon / demo team

**Scene:** Team needs to show judges a coherent AI workflow story.

**Pain:** Live demos look messy when history is a random sidebar.

**With Tecora:** Pre-tag demo chats, pin the walkthrough thread, export a backup before the stage.

**Landing line:** Present the work, not the clutter.

---

## 8. Artifact / file recovery

**Scene:** Useful Claude artifact or ChatGPT file lives inside an old thread.

**Pain:** Hard to find; harder to export cleanly.

**With Tecora:** ZIP export harvests assets when possible; missing ones listed in `MISSING.md`.

**Landing line:** Export the conversation *and* the files when you can.

## Anti-use-cases (don’t imply)

- “Tecora replaces ChatGPT”
- “Tecora gives you unlimited messages”
- “Tecora syncs your team’s chats in the cloud”
- “Tecora summarizes all your chats with AI” (not a v0.1 feature)
